# AGS integration plans

Start from `offline-starter` and complete one plan at a time. The
[tutorial](../12-accelbyte-integration-guide.md) covers setup and the learning
sequence. Give an agent the specific plan file below; each contains the scope,
prerequisites, execution checklist, detailed connected design references,
acceptance checks, and a handoff prompt.

Online stages are unimplemented on the baseline starter. Reference descriptions
of the connected game are not evidence of completion on your branch.
